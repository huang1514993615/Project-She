# 本地个人数据

Node.js 服务会在此目录创建个人运行数据。项目不使用数据库。

| 文件或目录 | 用途 |
| --- | --- |
| `settings.json` | 角色、世界设定、剧情摘要、按角色 ID 保存的长期记忆、提示词和多人配置 |
| `chat-history.json` | 聊天记录 |
| `image-jobs.json` | 后台生图任务、尝试次数、最终提示词、AI 场景摘要和人物介绍快照 |
| `generated-images/` | 已从临时上游地址下载并永久保存在本机的图片 |
| `server.log` | Node 与 Vinext 运行日志 |

这些个人文件默认被 Git 忽略，不应上传。升级、迁移或排查问题前建议备份整个 `data` 目录。

图片档案独立于聊天历史，不会随对话压缩或清空而消失。相册不会展示失败任务，但失败记录会暂时保留在此文件中供排错。

不要手工删除状态为 `running` 的图片任务；服务重启时会自动把无法恢复的运行中任务标记为失败。更多说明见项目根目录的 `PROJECT_CONTEXT.md`。
